## GO-LIVE MECHANICS + KILL SWITCH (confirmed against the code 2026-06-19)

**GO is a DECISION, not an auto-flip to real money.** Live state today: magna53
`phase=paper`, `live_real_enabled=false`; `ENABLE_LIVE_MODE=false` (live account not
even wired). Real money requires a deliberate, staged, reversible sequence AFTER GO:
1. **GO** (size agreed) — nothing changes technically.
2. `ENABLE_LIVE_MODE=true` + verify live Alpaca keys + **FUND the account**; magna53
   `phase=live`, `live_real_enabled=FALSE`; deploy.
3. **🟡 STAGED-PAPER preview**: magna53 emits Telegram proposals (exact shares/entry/
   stop/risk$), NO auto-submit — observe real signals at zero risk.
4. `live_real_enabled=TRUE` → auto-submits to the live account at the agreed size.

**SIZING (operator decision 2026-06-19): size via `position_size_multiplier` ONLY**
(risk = 1% of equity/trade × multiplier, VIX-scaled; start ~0.25–0.5×). **Keep
`max_concurrent_positions` at the global 5 — do NOT cap at 2.** Operator rationale:
with a low win rate, failed trades would occupy 2 slots and block a real EP; shrink
per-trade dollars, not the slot count. Absolute $ scales with how much the live
account is funded.

**KILL SWITCH — one command, runtime, no restart (confirmed):** `/strategy disable
magna53` (Telegram) sets `enabled=FALSE` in mi_strategies + invalidates the registry
cache; the entry pipeline reads strategy state per-entry (entry_pipeline.py:286 →
`BLOCK_STRATEGY_DISABLED`), so the NEXT ORB entry is blocked immediately. Graduated:
`/strategy demote magna53` (live→paper, keeps paper trading); `LIVE_TRADING_ENABLED=
false` env = broad all-strategy kill but BOOT-READ → needs a restart/deploy (nuclear,
not the fast one). ⚠ Disabling stops NEW entries only — open positions keep their
resting broker stops; it does NOT auto-flatten (flatten = separate manual action).

**Global one-command real-money PAUSE — being added as #345 (HARD launch gate,
operator 6/19):** `/strategy disable` is per-strategy; `LIVE_TRADING_ENABLED=false`
is boot-read (needs a restart). #345 adds a runtime DB halt flag + `/pause`/`/resume`
that block ALL new real-money entries instantly, no restart. **Do NOT flip
`live_real_enabled=TRUE` until #345 is live + verified.**
