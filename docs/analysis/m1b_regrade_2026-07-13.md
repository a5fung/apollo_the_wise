**M1-b tests a DIFFERENT mechanism than the one `composite_authority` flips live.** What goes

validates the **#329 prompt-enrichment direction**, **NOT** the deterministic composition that
flips live. **This $5 run produced ZERO evidence on the live M1-d mechanism.**

## 🔎 Deeper rigor (2026-07-13, post-run): the EXISTING shadows can't evidence M1-d either

Chasing Option A ("lean on the deterministic shadow") surfaced a second, code-certain gap:

- **M1-d's boost only *changes* a MODERATE alert.** `compose_final_tier` moves the TIER
  (none→MODERATE→HIGH). A +1 on a HIGH alert **clamps to HIGH — a no-op**. So M1-d only
  actually acts by promoting a **MODERATE→HIGH** (a hot-theme name that fires an alert it
  wouldn't have) — that is the consequential population.
- **The theme shadows only ever logged HIGH alerts.** `log_theme_axis_shadow` +
  `log_theme_axis_adjusted_shadow` both sit under `if r.get("score_tier") == "HIGH":`
  (ep_detector.py:3254). So all 461 `mi_theme_axis_shadow` rows are HIGH — the tier where the
  boost does nothing — and the credit-boost log (`theme_axis_shadow_adjusted`) has **1 row**.
- **Net: no data — free OR paid — observes what M1-d actually does.** M1-b tested the wrong
  MECHANISM (judge-prompt vs deterministic compose); the shadows watched the wrong TIER (HIGH,
  where the boost clamps). The MODERATE→HIGH promotions M1-d would cause were never logged.

**Consequence for 7/18:** M1-d is **not signable on evidence** — there is no evidence on the
population it changes. This mirrors the HTF #397 situation (gate unreachable → DEFER, not
NO-GO). Two rigorous **$0** paths to actually get the evidence, both needing time/build:
- **(a) Forward shadow** — the wire-in is now deployed dark; extend the shadow gate to LOG
  (not act) what M1-d would do on MODERATE alerts, then let real MODERATE-in-hot-theme
  would-promotions + their forward outcomes accrue.
- **(b) Backfill** — reconstruct historical MODERATE EP alerts that were in Accelerating themes
  (as-of `mi_themes.theme_date <= alert_date`) ⋈ `mi_ep_scan_outcomes`, and test whether those
  would-promoted names behaved like HIGHs (deserved the +1). $0, buildable this week, real analysis.
